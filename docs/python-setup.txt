 1) Preparation
    - Get the home assistant "core" version number (Settings -> About)
    - Get the required python version number (Settings -> System -> Repairs, ... menu, System Information)

 2) In Visual Studio Code, install the Microsoft Python extension

 3) Install/update the required Python version as the machine's default Python
    - pymanager list --only-managed
    - pymanager uninstall <old-python-version> (if required)
    - pymanager install --update <python-version>
    - python --version
      (expect the Home Assistant python version)

 4) Deactivate any existing virtual environment if .venv exists
    - Check if there is a directory called .venv, and if so:
      deactivate
      Remove-Item -Recurse -Force ".venv"

 5) Create and activate a new virtual environment
    py -m venv .venv
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
    .\.venv\Scripts\Activate.ps1

 6) Confirm that the virtual environment uses the correct Python
    python --version
    python -c "import sys; print(sys.executable)"
    python -m pip --version
    (expect ...\.venv\Scripts\python.exe and ...\.venv\Lib\site-packages)

 7) Update pip and install HA
    python -m pip install --upgrade pip setuptools wheel
    python -m pip install "homeassistant==<version>"

 8) Verify
    python -c "import homeassistant; print(homeassistant.__file__)"
    (expect ...\.venv\Lib\site-packages\homeassistant\__init__.py)
    python -c "import importlib.metadata; print(importlib.metadata.version('homeassistant'))"
    (expect the exact installed Home Assistant core version)

 9) Add to .\.vscode\settings.json
    {
        "python.defaultInterpreterPath": "${workspaceFolder}\\.venv\\Scripts\\python.exe",
        "python.analysis.autoImportCompletions": true,
        "python.analysis.typeCheckingMode": "basic"
    }

10) In Visual Studio Code, select the virtual environment interpreter
    Ctrl+Shift+P
    Python: Select Interpreter
    Select .\.venv\Scripts\python.exe
